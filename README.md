# Efficient-ai-
The project investigated dynamic neural networks to enhance computational efficiency by selectively skipping layers during inference based on input complexity. This approach is particularly relevant for  real-time and resource-constrained environments such as mobile devices, IoT systems, and  embedded AI applications. This is an ai research project so there will be some slight difference on accuracy, memory usage and cpu usage when compared to ligjtweight cnn but the this project aims on FLOPs of the model where it less for owr reseach model.
